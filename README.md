# 생기부 쓰는 순식이

**교사의 자료와 관찰을 바탕으로, ChatGPT와 함께 학교생활기록부를 작성하고 다듬는 개인용 도구입니다.**

현재 버전: **v0.1.0 · 초기 테스트용 배포본**

학생 활동 자료, 교사 의견, 학교생활기록부 기재요령과 선생님의 문체를 한 화면에서 관리합니다. AI가 만든 본문은 직접 수정할 수 있고, 검토 결과는 원문 아래에서 따로 확인할 수 있습니다.

## 어떤 기록을 쓸 수 있나요?

| 기록 영역 | 작성에 사용하는 정보 |
| --- | --- |
| 교과 세부능력 및 특기사항 | 활동 설명, 학생 자료, 수행 수준, 교사 의견, 선택 평가기준표 |
| 자율·자치활동 | 활동 설명, 학생 활동 자료, 교사 의견 |
| 진로활동 | 활동 설명, 학생 활동 자료, 교사 의견, 학생별 진로 분야 |
| 동아리활동 | 동아리명·설명, 활동과 학생 자료, 교사 의견 |
| 행동특성 및 종합의견 | 학생 특징·키워드, 교사 코멘트 |
| 개인별 세부능력 및 특기사항 | 활동 설명, 학생 활동 자료, 교사 의견 |

행동특성 및 종합의견을 제외한 영역에서는 **학생 한 명씩 작성**과 **한 활동으로 여러 학생 작성**을 선택할 수 있습니다. 행동특성 및 종합의견은 학생별 특징과 코멘트를 입력하는 목록으로 작성합니다.

## 주요 기능

- **자료 첨부·분석:** PDF, 이미지, DOCX, XLSX, HWP(5.x), HWPX와 텍스트 자료를 첨부합니다. 분석 버튼을 누르면 GPT가 읽고 정리하며, 정리된 글은 교사가 자유롭게 수정합니다. 손글씨 판독 결과도 검수할 수 있습니다.
- **공통 지침 재사용:** 확인·저장한 생기부 기재요령 요약, 작성 대상, 문체 분석을 모든 작성·검토 요청의 맨 앞에 배치합니다. 긴 공통 원문을 매번 다시 전달하지 않습니다.
- **영역별 프롬프트:** 기본 프롬프트 여섯 개를 제공하며, 각 영역에 연결할 프롬프트를 직접 선택·수정할 수 있습니다.
- **분량 확인:** 활동별 또는 학생별 목표 바이트 범위를 지정하고 실제 본문 분량을 확인합니다.
- **원문 편집·검토:** 원문을 직접 수정하고, 별도 검토본에서 변경 부분을 색으로 비교한 뒤 적용할 수 있습니다.
- **작성 기록·데이터 관리:** 작성 기록 조회, 설정 백업·불러오기, 선택 자동저장·복구, 학생 데이터 초기화를 지원합니다.
- **화면 설정:** 가로·세로 모드, 라이트·다크 모드와 색상 테마, 글꼴·글씨 크기를 선택합니다.
- **모든 사용자에게 제공하는 개발자 도구:** 프롬프트 로그, 역할별 편집, 생성 가이드, 프롬프트 JSON 가져오기·내보내기를 제공합니다. 로그에는 입력·출력과 검토 근거 요약을 보여주며 모델의 내부 추론 원문은 표시하지 않습니다.

Releases에 파일이 아직 없다면 배포 준비 중입니다. GitHub가 자동으로 제공하는 `Source code (zip)` 대신 이름에 `saenggibu-studio`와 `local.zip`이 들어간 배포 파일을 받으세요.

## 설치 안내

현재 배포본은 **사용자의 컴퓨터에서 실행하는 MCP 플러그인 패키지**입니다. MCP는 순식이의 화면·자료와 GPT를 연결하는 통로입니다. 일반 ChatGPT 대화에 ZIP을 첨부하는 것만으로 설치되지는 않습니다.

### 1. 실행 준비

1. ZIP을 내려받아 압축을 풉니다. 안에 있는 `saenggibu-studio` 폴더를 보관합니다.
2. 컴퓨터에 **Node.js 22.18 이상**을 설치합니다. Node.js는 순식이를 실행하는 데 필요합니다.
3. Windows에서는 폴더 안의 **`setup.cmd`를 두 번 클릭**합니다.
4. 준비가 완료되었다는 메시지가 나오는지 확인합니다.

최초 준비에는 인터넷이 필요합니다. PDF·이미지 처리에 필요한 실행 파일만 추가로 설치하며, 개발용 프로그램 전체를 받지는 않습니다. 설치 후 디스크 사용량은 압축 ZIP의 용량보다 커집니다.

macOS/Linux에서는 압축을 푼 폴더에서 `node scripts/setup.mjs`를 실행합니다. 해당 운영체제에서의 실제 설치·실행은 추가 확인이 필요합니다.

### 2. GPT에 연결

**로컬 플러그인 실행을 지원하는 데스크톱 환경**에서는 배포 폴더를 해당 호스트의 로컬 플러그인 설치 절차로 등록합니다. 폴더에 들어 있는 `plugin.json`, `mcp.json`, `skills`가 플러그인 정보·실행 방법·GPT 작업 지침을 제공합니다. 로컬 마켓플레이스를 사용하는 환경에서는 목록에 배포 폴더를 등록한 뒤 플러그인 목록에서 설치합니다.

**ChatGPT 웹 등 로컬 프로그램을 직접 실행하지 않는 환경**에서는 실행 중인 순식이와의 MCP 연결이 추가로 필요합니다. 공식 문서가 안내하는 공개 HTTPS 주소 또는 Secure MCP Tunnel 연결을 사용하며, ZIP만으로 이 연결이 생기지는 않습니다. 사용할 수 있는 연결 메뉴와 권한은 계정·환경에 따라 다릅니다.

연결 후 새 대화에서 순식이 플러그인을 선택하고 **“생기부 쓰는 순식이를 열어줘”**라고 요청합니다.

현재 배포본은 로컬 도구·화면·PDF/문서 판독·저장 동작을 검증했습니다. **ChatGPT에 설치한 상태의 전체 작성 과정은 연결 후 확인해야 합니다.** 상세한 실행 명령과 연결 방식은 ZIP 안의 `README.md` 및 [공식 연결 안내](https://developers.openai.com/plugins/deploy/connect-chatgpt)를 참고하세요.

## 처음 사용하는 순서

1. **설정 → 생기부 설정**에서 기재요령을 첨부하고 분석합니다. 요약을 확인·수정한 뒤 저장합니다.
2. 학년도·학교급·학년·과목 등 작성 대상을 설정합니다. 원하는 경우 내가 쓴 생기부 예시를 첨부·분석하여 문체 지침을 저장합니다.
3. 작성할 기록 영역과 작성 방식을 선택합니다. 과세특에서는 필요한 경우 평가기준표도 첨부합니다.
4. 활동·학생 자료·교사 의견과 목표 분량을 입력합니다. 첨부 자료의 분석 내용은 직접 검수합니다.
5. **작성**을 누릅니다. 나온 본문을 수정하고 **검토**로 기재요령과 표현을 확인합니다.

필수 입력을 채우기 전에도 작성 화면과 설정을 둘러볼 수 있습니다. 실제 분석·작성·검토는 연결된 GPT가 처리하며 별도의 AI 생성 API를 호출하지 않습니다.

## 자료는 어디에 저장되나요?

배포본의 학생 자료·작성 결과·기록·프롬프트·설정은 사용자의 컴퓨터에 저장됩니다.

- **Windows:** `%LOCALAPPDATA%\saenggibu-studio\data`
- **macOS/Linux:** `~/.local/share/saenggibu-studio/data`

프로그램 폴더와 자료 폴더를 분리하여 새 버전으로 교체해도 기존 자료를 계속 사용할 수 있도록 구성했습니다. 기존 개발 폴더의 자료는 자동으로 이동하지 않습니다.

**GPT가 분석·작성할 때는 작업에 필요한 자료가 연결된 GPT로 전달됩니다.** 로컬 저장과 GPT로의 자료 전달은 별개입니다. 배포 ZIP에는 개발자의 학생 자료·작성 기록·개인 설정·인증 키가 들어 있지 않습니다.
